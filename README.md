# Vue H5 Template Documentation

该分支维护 Vue H5 Template 的 VitePress 文档，不包含应用源码。

- 简体中文：`docs/guide`
- English: `docs/en/guide`
- VitePress 配置：`docs/.vitepress/config.js`

## 本地开发

```bash
pnpm install
pnpm dev
```

构建检查：

```bash
pnpm check
```

文档内容应以 `vue-h5-template` 分支的当前实现为准。新增或修改功能时，需要同步更新中英文页面及侧边栏。
