# 国际化

语言文件位于：

```text
src/locales/langs/
├── en-US/common.json
└── zh-CN/common.json
```

`src/locales/index.ts` 使用 `import.meta.glob` 扫描 JSON，并按 `语言/命名空间` 懒加载。当前语言保存在 localStorage 的 `lang` 键中，默认值为 `zh-CN`。

## 新增语言

1. 创建 `src/locales/langs/<locale>/common.json`。
2. 保持各语言的键结构一致。
3. 调用 `setLang('<locale>')` 切换语言。

```ts
import { setLang } from '@/locales'

await setLang('en-US')
```

切换后，模块会设置 Vue I18n locale、持久化选择，并同步更新 `<html lang>`。

页面路由标题保存的是翻译键，例如 `common.tabbar.home`，布局通过 `$t($route.meta.title)` 渲染。
