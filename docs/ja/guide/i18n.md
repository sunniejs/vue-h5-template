# 国際化

対応 Locale は `zh-CN`、`en-US`、`ja-JP` です。Home の Selector は `setLang` を呼び、Message を Lazy Load して `vue-i18n` の Reactive Locale、`localStorage`、HTML `lang` を同期します。

画面に直接固定文言を書かず、すべての翻訳可能な UI は Locale JSON に置きます。商品 Content は Backend の Localized Field から現在の Locale を選択します。

Locale 追加時は Message Key の同期、Router Title、E2E 切替、日付・金額 Formatter、Fallback を確認してください。
