# Internationalization

Locale files live under:

```text
src/locales/langs/
├── en-US/common.json
└── zh-CN/common.json
```

`src/locales/index.ts` scans JSON with `import.meta.glob` and lazy-loads messages by locale and namespace. The selected locale is stored under the `lang` localStorage key; `zh-CN` is the default.

## Add a Locale

1. Create `src/locales/langs/<locale>/common.json`.
2. Keep message keys aligned across locales.
3. Call `setLang('<locale>')`.

```ts
import { setLang } from '@/locales'

await setLang('en-US')
```

The loader updates Vue I18n, persists the selection, and synchronizes the document's `lang` attribute.

Route titles store translation keys such as `common.tabbar.home`; the layout renders them through `$t($route.meta.title)`.
